# spring-url-shortener

A small URL shortener service built with **Spring Boot 3** and **Java 21**. Codes are generated by encoding the database id in **Base62**, so they are short, unique and need no collision checks.

## Features

- `POST /api/shorten` creates a short code for an `http(s)` URL
- `GET /{code}` redirects (HTTP 302) and counts the click
- `GET /api/stats/{code}` returns clicks and creation time
- URL validation (rejects `javascript:`, `ftp:` and malformed input)
- Unit tests for the Base62 encoder and MockMvc integration tests
- H2 by default, MySQL with the `mysql` profile

## Stack

Java 21 · Spring Boot 3.3 · Spring Data JPA · H2 / MySQL · Maven · JUnit 5

## Run

```bash
mvn spring-boot:run

curl -X POST localhost:8080/api/shorten -H 'Content-Type: application/json' \
  -d '{"url":"https://github.com/guillegomezlopez3"}'
# {"code":"g8","shortUrl":"http://localhost:8080/g8", ...}

curl -i localhost:8080/g8          # 302 redirect
curl localhost:8080/api/stats/g8   # clicks counter
```

## Tests

```bash
mvn test
```

## How the codes work

The row is saved first to get its auto-increment id. The code is `Base62(id + 1000)`. The offset avoids one-character codes, and decoding gives back the id if you ever need to look rows up by primary key.
